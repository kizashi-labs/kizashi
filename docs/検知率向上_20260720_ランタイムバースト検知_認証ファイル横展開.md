# 検知率向上 2026-07-20(2) — ランタイム・バースト検知（認証攻撃／ランサム／横展開）

## 背景

侵入の主要フェーズの多くは **レート/ファンアウト現象**であり、単発イベントを見る Sigma/DBルールでは原理的に検知できない。実際にコードを当たると、以下が**リアルタイムでは未カバー**だった:

| 攻撃 | 現状 | 問題 |
|---|---|---|
| ブルートフォース/スプレー | builtin「Multiple Failed Login」は `EventID:4625` 1件で発火 | **回数を数えていない**。失敗1件ごとに鳴るだけで攻撃を検知しない。真のカウントは offline batch(insider_threat_detector, audit_logs)のみ＝リアルタイム性なし |
| ランサム暗号化 | 拡張子/ツールベースの sequence rule | 既知シグネチャ依存。新種・拡張子可変を取りこぼす |
| 横展開 | PsExec 等の単発 process rule | 1台が多数ホストへ広がる「面」を見ていない |

これらは実績ある `NetworkScanDetector`(T1046) と同型の**ステートフル・バースト検知器**で埋められる。テレメトリ(auth: `success`/`source_ip`/`username`、file: `path`/`action`/`process_name`、network: `dst_ip`/`dst_port`)は揃っている。

## 実装（3つの検知器、いずれも detection サーバ `processEventData` に接続）

### ⑨ 認証攻撃（`auth_attack.go`）
- **ブルートフォース(T1110)**: 単一アカウントへ窓(5分)内 `bruteMinFails`(6)回失敗で発火。**成功でカウンタをリセット**し「パスワード失念→再試行→成功」を除外。
- **パスワードスプレー(T1110.003)**: 単一 `source_ip` が窓内 `sprayMinAccounts`(6)個の**異なるアカウント**に失敗で発火（広く浅い＝単一アカウント型が取りこぼす形）。
- kill-chain に **credential-access 段**を供給。

### ⑩ ランサム的ファイル大量操作（`file_burst.go`）
- 単一プロセスが窓(30秒)内に `fileBurstMinFiles`(60)個の**異なるファイル**を**破壊的操作**(modify/write/overwrite/rename/delete/truncate/encrypt)で発火。**create/read は除外**しビルド・インストーラ等の正常I/Oを回避。
- **拡張子・ツール非依存**（挙動レートで判定）＝既知シグネチャの無い新種の暗号化にも反応。severity 9。kill-chain に **impact 段**。

### ⑪ 横展開ファンアウト（`lateral_fanout.go`）
- 単一ホストが窓(2分)内に `lateralMinHosts`(8)個の**異なる宛先ホスト**へ**リモート管理ポート**(SMB/RDP/WinRM/SSH/WMI/VNC)接続で発火。netScan の「1ホスト×多ポート(縦)」に対し「1ホスト×多ホスト(横)」を捕捉。kill-chain に **lateral-movement 段**。

いずれも matches に追加されるため、**kill-chain 相関へ自動供給**される（別配線不要）。`NetworkScanDetector` と同じ構造（スライディング窓・キー別状態・発火後dedup・決定的クロック・キー数上限でのevict）。

## 誤検知への配慮
- **認証**: 成功でブルートフォースをリセット。スプレーは「異なるアカウント多数」という特異条件。閾値 `bruteMinFails`/`sprayMinAccounts`/`authWindow` で調整可。
- **ファイル**: 破壊的操作のみ計数（create/read除外）、**同一ファイルの反復書き込みは1パス**として扱う、プロセス別キーで按分。閾値高め(60/30秒)。
- **横展開**: リモート管理ポートのみ、**同一ホストへの反復は1ホスト**、非サービスポート(443等)は無視。
- FP が出た場合は suppression / `CurateScheduler.MonitorFP` / 閾値定数で個別調整可能。

## テスト
- 認証: ブルートフォース発火/成功リセット/スプレー発火/少数無音/窓外失効/`authSucceeded` 判定。
- ファイル: 大量改変発火/非破壊無視/同一パス無視/プロセス別按分/`isDestructiveFileAction` 判定。
- 横展開: 多ホスト発火/非サービスポート無視/同一ホスト反復無音/窓外失効。
- 相関連動: 4検知器の技術(T1110/T1021/T1486/T1082)が kill-chain の異なる戦術にマップし1件に相関することを実証。
- `detection` パッケージ全 green・`go vet` clean。

## 効果
- **リアルタイム認証攻撃検知**（既存builtinの構造的欠陥＝カウントしない問題を是正）。
- **シグネチャ非依存のランサム検知**（挙動レート）。
- **横展開の面的検知**。
- 3種とも kill-chain 相関に自動供給され、多段侵入の相関検知率も底上げ。
