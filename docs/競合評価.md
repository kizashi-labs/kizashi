## 7. 強みと差別化ポイント

### Kizashiの主な優位点

#### 1. 完全なデータ主権・プライバシー
- オンプレミス展開でデータが外部に出ない
- エアギャップ環境（インターネット非接続）でも全機能利用可能
- ソースコードの透明性（社内展開時）

#### 2. 柔軟なAIプロバイダー選択
- 4社11モデルから用途・予算・セキュリティポリシーに応じて選択
- ローカルAI（Ollama）で機密データをAIに送信せずに分析
- AIによるルール自動生成（他社にない機能）

#### 3. 圧倒的な導入容易性
- Docker Compose 1コマンドで起動（`docker compose up -d`）
- セットアップ時間 < 30分
- 専門知識・コンサルティング不要

#### 4. 高い統合性
- Wazuh連携（他の主要EDR製品では非対応）
- SigmaHQ自動同期（コミュニティルールの継続的取り込み）
- MISP/OpenCTI互換のTIフィード管理

#### 5. 低コスト
- ライセンス費用ゼロから始められる
- AI機能はAPIキーの従量課金のみ
- 運用自動化による工数削減

### 競合製品の優位点（Kizashiの課題）

| 課題 | 該当製品 | 詳細 |
|------|---------|------|
| 独自グローバルTI | CrowdStrike / SentinelOne | 世界中のセンサーから収集した固有の脅威情報 |
| ロールバック機能 | SentinelOne (Storyline) | 感染前状態への完全ロールバック |
| ベンダーサポート | 全競合 | 24/7有償サポート・SLA保証 |
| 長年の実績・知名度 | CrowdStrike / Defender | 大規模企業での採用実績・ブランド信頼性 |
| モバイル実機検知（オンデバイス収集） | Lookout / Zimperium / Defender / Falcon Mobile / SentinelOne | 出荷済みオンデバイスエージェントで実機の脅威をリアルタイム収集・検知。本製品は**検知ロジック/surface は MTD 相当を実装済み（下記）だが、オンデバイス収集側が未稼働＝実機の実効検知は ~0%** |
