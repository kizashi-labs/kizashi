## 3. サポート範囲（スコープ）

### 3.1 サポートに含まれるもの（対象範囲）

以下の事項は、Kizashi サポートの対象となります。

**製品・機能に関するサポート**
- Kizashi エージェントのインストール・設定・アンインストール
- 管理コンソールの操作方法・設定手順に関するガイダンス
- アラート・インシデントの見方・トリアージ方法の説明
- 検知ルール（シグネチャ、YARA、Sigma）の設定方法（Professional / Enterprise）
- ライブレスポンス機能の操作方法（Professional / Enterprise）
- 対応プレイブックの設定方法（Professional / Enterprise）
- SIEM / SOAR / チケットシステムとの標準的な連携設定（Professional / Enterprise）
- REST API の利用方法・仕様に関する質問
- レポート・ダッシュボードのカスタマイズ方法

**障害対応・トラブルシューティング**
- 本サービスのサービス障害の受付・調査・解決
- エージェントの動作不良・クラッシュ・通信エラーのトラブルシューティング
- アラートが生成されない、または誤検知が多い場合の調査支援
- パフォーマンス問題（エージェントによる高CPU使用率等）の調査

**インシデント対応支援**
- セキュリティインシデント発生時の製品操作に関するガイダンス
- フォレンジック機能の利用方法の説明
- Professional プラン: 月4時間までのインシデント対応アドバイザリー
- Enterprise プラン: 月20時間までのインシデント対応技術支援

### 3.2 サポートに含まれないもの（対象外）

以下の事項はサポートの対象外となります（別途有償サービスとして提供可能な場合があります）。

**対象外の内容**
- お客様の一般的なセキュリティ運用コンサルティング（製品機能に直接関係しないもの）
- Kizashi以外の製品・ツールの操作方法に関するサポート
- お客様の社内ネットワーク環境・エンドポイント環境の設定変更
- お客様のOSやミドルウェアのトラブルシューティング（EDRエージェント起因でないもの）
- 脆弱性修正やパッチ適用の実施（エンドポイントへの直接作業）
- マルウェア除去のための手作業対応（本サービスの機能を超えるもの）
- カスタムスクリプト・コードの開発（別途カスタム開発支援サービスとして提供）
- トレーニング・研修（別途トレーニングサービスとして提供）
- 英語以外の言語での技術ドキュメント翻訳

## 4. テクニカルアカウントマネージャー（TAM）

### 4.1 TAMの提供対象

テクニカルアカウントマネージャー（TAM）は、**Enterprise プランのお客様専用** のサービスです。

> **注記:** Professional プランのお客様には TAM は配置されませんが、担当カスタマーサクセス担当者（プール型）がサポートポータルおよびメールを通じてサポートします。

### 4.2 TAMの役割と責任範囲

TAMはお客様の技術的な主窓口として、以下の役割を担います。

**定常的なサービス管理**
- お客様のサービス利用状況・稼働状況の定期モニタリング
- 月次レビューミーティングの実施（オンライン、月1回以上）
- 四半期ビジネスレビュー（QBR）の調整・実施
- 新機能リリース・アップデートに関する事前説明と影響分析

**技術的支援**
- 製品設定・アーキテクチャに関するベストプラクティス提供
- お客様環境に合わせた検知ルールの最適化アドバイス
- SIEM/SOARとの統合設計・最適化支援
- カスタム対応プレイブックの設計支援

**インシデント対応時の連携**
- P1/P2障害発生時のお客様とサポートチームのブリッジ役
- エスカレーション先の調整・管理
- 障害事後報告書のレビューと説明

**戦略的アドバイザリー**
- お客様のセキュリティ成熟度向上に向けたロードマップ提案
- 新機能・アドオンの採用検討に関する技術的アドバイス
- 製品ロードマップに関する優先情報の共有（NDA前提）

### 4.3 TAMの連絡方法

- 専用メールアドレス（TAM個人アドレス、契約時に案内）
- Slack 共有チャンネル内での直接コミュニケーション
- 定例ミーティング（Google Meet / Microsoft Teams、お客様の希望に合わせて設定）

> **注記:** TAMへの直接連絡は P1障害の正式な報告経路ではありません。P1障害は必ずサポートポータルまたは専用ホットラインを通じて報告してください。TAMは並行して状況把握と調整を行います。

## 5. 問い合わせポータルの利用方法

### 5.1 アクセス

- **URL:** https://support.kizashi-edr.jp
- 管理コンソールのアカウントと同一の認証情報（SSO対応）でログイン可能です

### 5.2 主要機能

| 機能 | 説明 |
|------|------|
| **チケット作成** | 技術的な問い合わせ・障害報告を新規チケットとして登録 |
| **チケット管理** | 進行中・解決済みチケットの一覧確認・コメント追加 |
| **SLAクレジット申請** | サービスクレジット申請フォームへのアクセス |
| **ナレッジベース** | 製品ドキュメント・FAQ・操作手順書の参照 |
| **リリースノート** | 最新バージョンのリリース情報・変更履歴の確認 |
| **ステータス確認** | サービス稼働状況・メンテナンス予定の確認 |
| **トレーニング動画** | 基礎・運用・高度操作の動画トレーニングコンテンツ |

### 5.3 チケット作成時の推奨事項

障害報告チケットを作成する際は、以下の情報を可能な限り含めてください。迅速な対応に役立ちます。

- 障害の概要（何が起きているか、いつから発生しているか）
- 影響を受けているコンポーネント・機能
- 影響を受けているエンドポイント数またはユーザー数
- 障害が発生した操作手順（再現可能な場合）
- スクリーンショット・エラーメッセージ・ログ（添付可）
- テナントID（管理コンソールの「設定 > テナント情報」で確認可）
- エージェントバージョン（該当する場合）

### 5.4 チケット優先度の設定

チケット作成時に優先度（P1〜P4）を選択してください。選択された優先度に基づきSLAの応答時間が適用されます。優先度の定義はSLA定義書（`docs/legal/sla.md`）第4条を参照してください。

## 6. エスカレーション手順

### 6.1 エスカレーション体制

Kizashi のサポート組織は以下の4層構造で構成されています。

```
L1: フロントラインサポートエンジニア
    ↓（解決不可・条件充足時）
L2: シニアサポートエンジニア
    ↓（解決不可・条件充足時）
L3: テクニカルサポートマネージャー / 製品スペシャリスト
    ↓（重大障害・経営判断が必要な場合）
開発チーム（Engineering）/ CTO / CEO
```

詳細なエスカレーションフロー、連絡先、各ロールの責任範囲については、エスカレーションマトリクス（`docs/support/escalation-matrix.md`）を参照してください。

### 6.2 自動エスカレーション基準

以下の条件が満たされた場合、当社は自動的に上位層へエスカレーションします。

| 条件 | エスカレーション先 |
|------|:----------------:|
| P1障害で初期応答時間内に応答できない場合 | L2（即時） |
| P1障害で初回応答から2時間以内に解決策の見通しが立たない場合 | L3 |
| P1障害で初回応答から4時間以内に解決しない場合（Enterprise） | CTO通知 |
| P2障害で4時間以内に応答できない場合 | L2 |
| P2障害でSLA解決目標時間の50%経過時点で解決していない場合 | L3 |
| 同一障害の再発（30日以内に3回以上） | L3 / 製品チームレビュー |

### 6.3 お客様からのエスカレーション要求

お客様がサポート対応に不満を持つ場合、または対応の遅延・内容に問題があると判断した場合、以下の方法でエスカレーションを要求できます。

1. **サポートポータル:** 対象チケットの「エスカレーション要求」ボタンをクリック
2. **メール:** support@kizashi-edr.jp 宛に件名「[エスカレーション要求] チケット番号: XXXXX」として送付
3. **Enterprise TAM経由:** TAMに直接連絡し、エスカレーションを依頼

エスカレーション要求を受けた場合、当社は **30分以内**（Enterprise）または **2時間以内**（Professional）にシニアサポートエンジニアが対応状況を確認し、お客様に連絡します。

## 7. オンサイトサポート

### 7.1 提供対象

オンサイトサポートは **Enterprise プランのお客様向けオプションサービス** です。

### 7.2 提供内容

オンサイトサポートでは、当社のエンジニアがお客様のオフィス・データセンターに訪問し、以下のサービスを提供します。

**技術支援系**
- 複雑な環境への Kizashi 展開・設定支援
- オンプレミス展開（エアギャップ環境を含む）のセットアップ支援
- 既存セキュリティエコシステムとの統合設計・実装支援
- 大規模インシデント発生時の現地フォレンジック支援
- セキュリティアーキテクチャのレビューとベストプラクティス適用支援

**トレーニング系**
- SOCチーム向けハンズオントレーニング（Kizashi 操作）
- 管理者・アナリスト向けカスタムトレーニング
- インシデント対応訓練（テーブルトップエクササイズ）

### 7.3 費用

オンサイトサポートは以下の料金が発生します（Enterprise プランに含まれるオンボーディング支援分を除く）。

| 費用区分 | 内容 |
|---------|------|
| **人件費** | ¥150,000/人日（エンジニア1名あたり） |
| **交通費・宿泊費** | 実費（東京23区外の場合） |
| **最小契約日数** | 1日（半日対応の場合は¥90,000/人） |

> 事前に見積もりを提出しますので、営業担当または TAM までご連絡ください。

### 7.4 申し込み手順

1. TAM または sales@kizashi-edr.jp に訪問支援の依頼を行う
2. 当社担当者が日程・内容・費用見積もりを提示（依頼から3営業日以内）
3. お客様が見積もりを承認し、訪問日程を確定
4. 訪問実施、終了後に訪問報告書を提出（5営業日以内）
