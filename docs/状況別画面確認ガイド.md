# Kizashi — 状況別 画面確認ガイド

> **対象読者:** SOCアナリスト・セキュリティ担当者・IT管理者
> **最終更新:** 2026-05-07

---

## 🔴 緊急時・インシデント発生時

| シチュエーション | 確認する画面 | URL | 見るべきポイント |
|----------------|------------|-----|----------------|
| **「何か変なことが起きている」と感じたとき** | SOCワークキュー | `/soc-queue` | 「今すぐ対応」レーンに何件あるか |
| **Critical/Highアラートが来た** | アラート詳細 | `/alerts/[id]` | AI分析結果・プロセスツリー・推奨対応 |
| **ランサムウェア疑い** | SOCワークキュー → エンドポイント | `/soc-queue` → `/endpoints/[id]` | 端末の即時隔離ボタン |
| **端末が感染した可能性** | エンドポイント詳細 | `/endpoints/[id]` | ライブレスポンス → ファイル検疫 |
| **自社がダークウェブに載った** | ダークウェブ監視 | `/threat-intel/darkweb` | 検知結果タブ・グループ名・説明 |
| **インシデントを調査したい** | インシデント管理 | `/incidents/[id]` | タイムライン・関連アラート・対応メモ |

---

## 🟠 毎日の定常確認（始業時 〜15分）

| タイミング | 確認する画面 | URL | 確認内容 |
|----------|------------|-----|---------|
| **1. まず最初に** | ダッシュボード | `/` | SOCキューウィジェットで緊急件数を把握 |
| **2. 詳細確認** | SOCワークキュー | `/soc-queue` | 3レーン（今すぐ/今日中/今週中）を確認 |
| **3. 夜間のPlaybook実行確認** | インシデント管理 | `/incidents` | 新規インシデントが自動作成されていないか |
| **4. オフライン端末の確認** | エンドポイント一覧 | `/endpoints` | 赤いボーダーの端末（オフライン）を確認 |
| **5. AI自動クローズの確認** | アラート一覧 | `/alerts?status=false_positive` | AIが誤検知と判断したものを確認 |

## 🟡 週次・定期確認（週1回 30〜60分）

| シチュエーション | 確認する画面 | URL | 確認内容 |
|----------------|------------|-----|---------|
| **今週の攻撃傾向を把握** | MITREマトリクス | `/mitre` | どのテクニックが多く検知されたか |
| **ノイズアラートを減らしたい** | SOCワークキュー | `/soc-queue` | 「抑制候補」セクションで繰り返しアラートを確認 |
| **脅威グループの動向確認** | 脅威インテリジェンス | `/threat-intel` | 脅威アクタータブ・IOC検索 |
| **YARA/Sigmaルールの見直し** | YARAルール管理 | `/yara` | 有効ルール・マッチ数・カテゴリバランス |
| **コンプライアンス状況確認** | コンプライアンス | `/compliance` | NISTスコア・MITREカバレッジ |
| **レポート生成** | レポートビルダー | `/reports/builder` | 週次レポートを自動生成 |

## 🔵 特定のシチュエーション別

### 端末・エージェント関連

| シチュエーション | 画面 | URL |
|----------------|------|-----|
| 新しい端末を登録したい | エンドポイント一覧 | `/endpoints` |
| 端末のソフトウェア一覧を見たい | 端末詳細 → ソフトウェアタブ | `/endpoints/[id]` |
| 端末のログを収集したい | 端末詳細 → ライブレスポンス | `/endpoints/[id]` |
| 端末を一時的に隔離したい | 端末詳細 → 「隔離」ボタン | `/endpoints/[id]` |
| エージェントが応答しない | エンドポイント一覧 | `/endpoints?status=offline` |

### アラート・インシデント関連

| シチュエーション | 画面 | URL |
|----------------|------|-----|
| 特定ホストのアラートを絞り込む | アラート一覧 | `/alerts?agent_id=...` |
| アラートの関連プロセスを見たい | アラート詳細 → プロセスツリー | `/alerts/[id]` |
| 同じルールで何回も発生している | アラート一覧 → グルーピング表示 | `/alerts` |
| インシデントを手動で作成したい | インシデント管理 | `/incidents` → 「+新規」 |
| 攻撃の全体像を把握したい | インシデント詳細 → タイムライン | `/incidents/[id]` |

### セキュリティ設定関連

| シチュエーション | 画面 | URL |
|----------------|------|-----|
| 特定のアラートを今後無視したい | 抑制ルール | `/suppressions` |
| 特定条件で自動対応を設定したい | Playbook | `/admin/playbooks` |
| 監視対象キーワードを追加したい | ダークウェブ監視 | `/threat-intel/darkweb` → 監視設定タブ |
| YARAルールを追加したい | YARAルール管理 | `/yara` → 「ルールを追加」 |
| 通知先を変更したい | 通知設定 | `/settings/notifications` |
| ダークウェブ通知を設定したい | 通知設定 → デイリーブリーフィングタブ | `/settings/notifications` |

### 調査・フォレンジクス関連

| シチュエーション | 画面 | URL |
|----------------|------|-----|
| 不審なIPやハッシュを調べたい | IOC検索 | `/threat-intel` → IOC検索タブ |
| メモリダンプを取得したい | フォレンジクス → メモリ | `/forensics/memory` |
| ネットワーク通信を調べたい | フォレンジクス → ネットワーク | `/forensics/network` |
| マルウェアファミリーを調べたい | マルウェア分析 | `/malware-analysis/families` |
| 脅威ハンティングをしたい | 脅威ハンティング | `/threat-hunting` |

## 画面の優先度マトリクス

```
重要度
  高  │  SOCキュー    アラート詳細
      │  インシデント  エンドポイント詳細
      │
  中  │  ダッシュボード  MITRE       YARA
      │  コンプライアンス 脅威インテリジェンス
      │
  低  │  レポート     フォレンジクス  設定画面
      └────────────────────────────────────
         毎日         週次          月次/都度
                   確認頻度
```

---

## 1日の標準的な確認フロー

```
【始業（〜15分）】
ダッシュボード → SOCキュー → エンドポイント確認

【日中（必要に応じて）】
アラート対応 → インシデント調査 → 抑制ルール作成

【夕方（〜10分）】
コンプライアンス確認 → 今週中レーンの消化

【週次（30〜60分）】
MITREマトリクス → YARA見直し → 週次レポート生成
```

## よくある「どこを見ればいい？」への回答

| 質問 | 答え |
|------|------|
| 「今、会社は安全？」 | ダッシュボード → SOCキューウィジェット |
| 「昨夜何かあった？」 | SOCキュー「今すぐ対応」レーン |
| 「なぜこのアラートが出た？」 | アラート詳細 → プロセスツリー・AI分析 |
| 「この端末は感染してる？」 | エンドポイント詳細 → ライブレスポンス |
| 「自社の情報が漏れてる？」 | ダークウェブ監視 → 検知結果タブ |
| 「どの攻撃が多い？」 | MITREマトリクス（All フィルター） |
| 「コンプライアンスは大丈夫？」 | コンプライアンス → NISTスコア |
| 「誰がいつ何をした？」 | 監査ログ（管理者のみ） |
