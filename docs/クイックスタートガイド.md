# Kizashi — クイックスタートガイド

**対象読者:** 初めて Kizashi を利用する管理者・SOCアナリスト  
**所要時間:** 約 15〜30 分  
**最終更新:** 2026-06-03

---

## このガイドの目的

本ガイドでは、Kizashi を初めて起動してから最初のエンドポイントを保護するまでの最短手順を説明します。詳細な設定や全機能の説明は [ユーザーガイド](ユーザーガイド.md) と [管理者運用ガイド](管理者運用ガイド.md) を参照してください。

---

## ステップ 1 — ログインとパスワード変更（5 分）

### 初回ログイン

1. ブラウザで管理者から共有された URL（例: `https://your-edr.example.com`）を開く
2. 以下のデフォルト認証情報でログイン

   | 項目 | 値 |
   |------|-----|
   | メールアドレス | `admin@example.com` |
   | パスワード | `Admin1234!` |

3. ログイン後、右上のユーザーアバター → **プロフィール** → **パスワード変更** からパスワードを変更する

> **重要:** デフォルトパスワードのまま運用しないでください。

### 画面構成の確認

| エリア | 説明 |
|--------|------|
| 左サイドバー | 機能ナビゲーション（折りたたみ可） |
| トップバー右上 | 検索（`Ctrl+K`）、通知ベル、ユーザーメニュー |
| メインエリア | 各機能の操作画面 |

## ステップ 2 — 最初のエンドポイントを登録（10 分）

### エンロールメントトークンの確認

1. 左サイドバー **管理 → 管理 & 設定 → エージェント登録承認** を開く
2. **登録トークン** をコピーする（エージェントのインストールに必要）

### エージェントのインストール

#### Windows

管理者権限の PowerShell で実行：

```powershell
# インストーラーをダウンロード（URL はサーバー管理者から取得）
Invoke-WebRequest -Uri "https://your-edr.example.com/downloads/install.ps1" -OutFile install.ps1

# インストール実行（トークンとサーバーアドレスを指定）
.\install.ps1 -Token "<エンロールメントトークン>" -Server "your-edr.example.com:9091"
```

#### Linux

```bash
# インストーラーをダウンロード
curl -sSfL https://your-edr.example.com/downloads/install.sh | \
  EDR_TOKEN="<エンロールメントトークン>" \
  EDR_SERVER="your-edr.example.com:9091" \
  sudo bash
```

#### macOS

```bash
# インストーラーをダウンロード
curl -sSfL https://your-edr.example.com/downloads/install-macos.sh | \
  EDR_TOKEN="<エンロールメントトークン>" \
  EDR_SERVER="your-edr.example.com:9091" \
  sudo bash
```

### 登録確認

インストール後 1〜2 分待ち、以下を確認します：

1. **エンドポイント → エンドポイント一覧** を開く
2. インストールした端末のホスト名が一覧に表示されること
3. ステータスが **オンライン**（緑）であること

> 表示されない場合は [トラブルシューティング](トラブルシューティング.md)（§1 エージェントの接続問題）を参照してください。

## ステップ 3 — ダッシュボードで状態を確認（3 分）

1. 左サイドバー **ダッシュボード** を開く
2. 以下を確認する

   | カード | 確認内容 |
   |--------|---------|
   | 総エンドポイント | 登録した端末数が反映されているか |
   | オンライン | 端末が「オンライン」にカウントされているか |
   | 未対応アラート | 初期値は 0（既存環境では検知があるかもしれない） |

---

## ステップ 4 — 検知ルールを確認（3 分）

1. **検知 → 検知ルール** を開く
2. デフォルトで有効なルールが一覧に表示されている（Sigma / YARA / Behavioral）
3. 組織の環境に合わせて不要なルールを無効化する（false positive 削減のため）

> ルールの追加・カスタマイズ方法は [ユーザーガイド § 9](ユーザーガイド.md#9-検知ルール管理) を参照してください。

---

## ステップ 5 — AI分析を設定する（5 分）

AI機能を有効にすることで、アラートの自動分析・対応推奨が利用できます。

1. 左サイドバー **設定** を開く
2. **AI分析設定** タブを選択
3. 使用するプロバイダー（Anthropic / OpenAI / Google）のタブを選択
4. APIキーを入力して **保存**

| プロバイダー | 推奨モデル | 用途 |
|------------|----------|------|
| Anthropic | Claude Sonnet 4.6 | バランスがよく日常運用に最適 |
| OpenAI | GPT-4o | 高精度な脅威分析 |
| Google | Gemini 2.0 Flash | 大量アラートの高速処理 |

> APIキーがない場合は AI機能なしでも EDR の基本機能（検知・対応・レポート）は利用できます。

---

## ステップ 6 — 通知チャンネルを設定する（任意）

重大アラートを Slack / メール / Teams に転送する場合：

1. **管理 → 管理 & 設定 → 通知チャンネル** を開く
2. **＋追加** をクリック
3. 種別（slack / email / teams / pagerduty）を選択して設定する

## よくある質問（FAQ）

**Q: エージェントが登録されない**  
→ ファイアウォールでサーバーの 8080（HTTP）と 9091（gRPC）ポートへのアウトバウンドが許可されているか確認してください。

**Q: アラートが来ない**  
→ 検知ルールが有効になっているか確認してください。テスト用に `/alerts/triage` でサンプルデータを確認することもできます。

**Q: 複数の管理者を追加したい**  
→ **管理 → 管理 & 設定 → ユーザー管理 → ＋招待** からユーザーを招待してください。

**Q: エンタープライズ機能（SSO/SIEM連携など）を設定したい**  
→ [管理者運用ガイド § 8](管理者運用ガイド.md#8-管理セクション) および [enterprise/SSO・LDAP連携.md](enterprise/SSO・LDAP連携.md) を参照してください。
