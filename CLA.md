## How to sign

Signing is handled through the pull request. In your **first** pull request to
this repository, add the following line to the pull request description,
replacing the placeholders:

```
I have read the CLA at CLA.md and I hereby sign it.
Name: <your name or handle>   GitHub: @<your-github-username>   Date: <YYYY-MM-DD>
```

A maintainer will record the signature. You only need to do this once; later pull
requests are covered by the same signature.

Contributions submitted **without** a recorded CLA signature cannot be merged.
